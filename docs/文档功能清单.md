# 文档编辑器（类 WPS 文字）完整功能清单

> 本清单参考 WPS 文字 / Microsoft Word 的功能划分，按模块整理。
> 标注说明：**【P0】** 基础必备，**【P1】** 常用进阶，**【P2】** 高级功能；**💰** 表示 WPS 中通常需要会员才能使用。

## 1. 文件管理

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 新建文档 | 空白文档、从模板新建 | P0 |
| 打开文档 | 支持 .docx / .doc / .wps / .txt / .rtf / .md / .odt | P0 |
| 保存 / 另存为 | 保存为 .docx、.doc、.wps、.txt、.rtf、.odt、.html | P0 |
| 自动保存 | 定时自动保存，崩溃恢复 | P0 |
| 最近文件 | 最近打开列表、固定常用文件 | P1 |
| 历史版本 | 查看 / 对比 / 回滚历史版本 💰 | P1 |
| 文档属性 | 标题、作者、创建/修改时间、字数统计 | P1 |
| 文档加密 | 打开密码、编辑密码 💰（部分） | P1 |
| 文档瘦身 / 压缩图片 | 减小文件体积 💰 | P2 |

## 建议的开发路线

1. **第一阶段（MVP）**：所有 P0 功能 —— 能打开/保存 .docx、完成基本文字排版、表格、图片、页眉页脚、目录、批注修订、导出 PDF、打印。
2. **第二阶段**：P1 功能 —— 样式管理、分栏、脚注、题注、文档比较、水印、公式、限制编辑、PDF 转 Word 等常见“会员功能”。
3. **第三阶段**：P2 功能 —— 在线协作、邮件合并、OCR、AI 写作助手、智能排版等。
