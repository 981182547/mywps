# 轻匣 —— 文件处理工具箱

本地运行、免费、无水印的桌面文件处理工具。所有文件只在本机处理，不上传任何服务器。

## 当前可用功能

| 工具 | 说明 |
| --- | --- |
| PDF 合并 | 多个 PDF 按顺序合并；可拖动排序；每个文件可单独指定页码范围（如 `1-3,5`、`8-`、`5-1` 倒序） |
| PDF 拆分 | 按固定页数拆分、按自定义范围拆分；多个结果自动放入单独文件夹 |
| 提取页面 | 挑出指定页面，另存为一个新 PDF |
| 图片转 PDF | JPG / PNG 合成 PDF；A4 / A3 / Letter / 同图片尺寸；自动横竖；**自动纠正手机照片方向** |

通用体验：

- 拖入文件自动推荐工具，`Ctrl + K` 搜索工具
- 默认保存在源文件所在文件夹，**重名自动编号，从不覆盖原文件**
- 先写临时文件再改名，处理失败不会留下损坏的半成品
- 加密、损坏、格式不支持的文件都会给出明确的中文提示
- 耗时处理在后台线程运行，界面不卡顿，显示实时进度
- 浅色 / 深色 / 跟随系统 三种主题

完整规划见 [docs/文件处理功能清单.md](docs/文件处理功能清单.md)。

## 开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev        # 开发模式启动
npm run build      # 构建
npm start          # 运行构建后的程序
```

如果安装后提示找不到 Electron，可执行 `node node_modules/electron/install.js` 重新下载。

## 测试

```bash
npm run typecheck  # 类型检查
npm test           # 单元测试：处理引擎、页码解析、真实渲染验证照片方向
npm run test:e2e   # 端到端测试：启动真实程序，模拟用户完成每个工具的操作
```

Linux 无显示器环境下运行端到端测试需要 `xvfb-run -a npm run test:e2e`。

## 目录结构

```
src/
  main/            主进程
    engine/        处理引擎（纯 Node，可单独测试）
    worker.ts      后台工作线程
  preload/         预加载脚本（安全地向界面暴露接口）
  renderer/        界面（React）
    src/tools/     各个工具页面与工具注册表
  shared/          主进程与界面共用的类型和页码解析
tests/
  unit/            单元测试
  e2e/             端到端测试
  fixtures/        测试用文件
```
